# Feature inventory (Phase 1) and implementation status

ADBPlus (Electron/React, AGPL-3.0, v1.20.0) was read **only as a reference** for
features, workflows, device operations and error handling. Nothing was ported;
the paths below are where the behaviour was observed in the legacy tree.

Columns used for each feature: workflow · legacy location · external tools ·
inputs/outputs · error cases · Rust implementation · verification · status.
"Verified" below means covered by the automated tests named; nothing here was
tested on a physical Android device (see README, "Test limits").

## Deliberately not reproduced

* Electron-specific shell: auto-update, custom title bar, i18n (UI is English only).
* Mirroring audio and recording (audio needs Opus decoding and an audio output; not implemented).
* Keystore creation (not an `apksigner` feature); use `keytool`.
